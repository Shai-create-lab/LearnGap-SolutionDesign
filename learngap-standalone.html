Architecture

Five stages, one human checkpoint

1 Diagnose

Adaptive check

Ten questions. Each next question comes from the weakest topic, at a matching difficulty.

2 Estimate

Mastery score

One score per topic, updated after every answer. The number of questions behind it is always shown.

3 Plan

Draft routine

Rules turn the three biggest gaps into a three-step routine with a plain reason for each choice.

4 Review

Teacher decides

The teacher approves, adds a note, or leaves the draft. The learner sees which one happened.

5 Track

Re-check

A short repeat check shows whether the gap closed. The class view groups learners for reteaching.

Where the AI sits

The prototype uses a transparent rule for mastery, so every score can be recomputed by hand. In a full build, a language model would write the step-by-step hints and the plain-language reasons. Its output would be checked against the CAPS Grade 8 topic list and held for teacher review before reaching a learner.

Privacy

No names, no accounts

Learners get a code such as L-0427. POPIA treats children's information as special, so school approval and a parent or guardian's consent come before any real use. Only scores and answers are kept, and the school holds the key that links a code to a child.

Fairness

Language is not ability

Items are in English. A learner who knows the maths can still miss a word problem because of the wording. Questions are kept short, and the full build adds translated versions checked by teachers. Error rates are compared across home language and school type before the tool is trusted.

Transparency

Every item says why

Each plan item shows the answers behind it and says when a score rests on only one or two questions. A learner can see the same reasons the teacher sees.

Human oversight

The teacher has the last word

Plans start as drafts. The teacher approves, adds a note, or ignores them. Nothing from this tool is used for marks, streaming or promotion decisions.

Reliability

Ten questions is a first look

A short check cannot measure a topic precisely. Scores are labelled as estimates, topics with a single question are flagged, and the Friday re-check gives a second reading before anyone acts.

Safety

No open chat with children

The full build writes hints from a fixed set of topics and does not let a learner type free messages to a model. Generated text is filtered and queued for teacher review.
